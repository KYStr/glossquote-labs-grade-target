使用說明

剩下的項目平均要多少才會達到目標？

工具先算已評分項目的加權貢獻，再用尚未評分的權重求出所需加權平均，向上取至 0.01 分。只適用於你輸入的分數與權重。

成績空白和輸入 0 有什麼不同？

空白表示尚未評分，不會當成 0 分；輸入 0 表示已評分且得 0 分。

所需平均是否代表每個剩餘項目都必須達到這個分數？

不是。這是依剩餘權重合併後的平均，不代表個別項目的最低分；實際結果仍取決於權重與分數。

如果工具說目標不可達，代表什麼？

即使所有空白項目都得到 100，依目前權重和已知分數算出的最高總成績仍低於目標。請核對輸入與學校官方規則。

工具會替我套用學校的計分規則嗎？

不會。工具不連接校務系統，也不知道曲線、類別權重、補考或其他校規；請以學校公布的規則為準。
